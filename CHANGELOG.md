# Журнал изменений

## 0.2.1

- Уточнён контракт `query-texts`: начальный перевод строки перед первой строкой
  `|...` в многострочном BSL-литерале не считается лишней пустой строкой.
- Запрещены style-only правки, которые переносят первую строку запроса на строку
  присваивания без изменения самого текста запроса.
- Закреплено правило пустых строк вокруг управляющих блоков BSL: блоки `Если`,
  `Для`, `Пока`, `Попытка` и подобные отделяются от линейных операторов и друг
  от друга, а вложенный управляющий блок в начале тела требует пустую строку на
  tab-уровне тела внешнего блока.

## 0.2.0

- Закреплён маршрут для задач только по стилю: задачи про `НЕ`/`ИЛИ`, форматирование,
  локальное именование, doc-comments и декомпозицию без запроса на `v8std`
  остаются в `1c-bsl-code-style`.
- Уточнено, что внешний `1c-bsl-review-standards` может использовать этот
  навык только как полный контрольный слой по `checks.jsonc`.

## 0.1.0

- Зафиксирована начальная версия отдельного репозитория навыка.
- Добавлен локальный контракт релиза для участия в `skills-1c-system`.
