# Правила skill repo `1c-bsl-code-style`

## Границы

- Это отдельный git repo навыка `1c-bsl-code-style`.
- Не редактировать соседние skill repo и meta repo без явного scope.
- После изменения публичного контракта обновить `VERSION`, `CHANGELOG.md`,
  `skill.json` и `.zcode-plugin/plugin.json`.

## Структура

- `SKILL.md` — тонкий публичный контракт: режимы, короткая процедура,
  жёсткие правила, ссылки на rule-паки.
- `references/` — канонические rule-паки; каждое правило живёт ровно в одном
  файле вместе с примерами.
- `profiles/` — project-specific профили, подключаются только при
  подтверждённой применимости.
- `scripts/bsl_style_check.py` — единый машинный guard детерминированных
  правил; его check-id должны оставаться синхронизированы с `references/`.
- `tests/` — тесты guard-а и контракта документации.

## Проверки

- Документацию и текстовые артефакты навыка писать на русском языке.
- Runtime-артефакты хранить вне skill tree, предпочтительно в `/tmp/1c-bsl-skills-pycache/1c-bsl-code-style`.
- Не фиксировать конкретную модель или `reasoning effort` внутри skill-а.
- Не возвращать процессный слой: coverage-manifest, owner-роли, субагентный
  контракт и отдельный examples-слой удалены осознанно; детерминированные
  правила развиваются через `scripts/bsl_style_check.py`, а не через прозу.
