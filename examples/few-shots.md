# Примеры

Этот файл относится к examples-layer и не закрывает checks сам по себе.
Это иллюстрации типовых решений, а не скрытый нормативный слой.

Его не нужно читать целиком по умолчанию.

Используйте только те примеры, которые реально соответствуют текущему типу
задачи. Большая часть примеров ниже относится к интеграционному и
orchestration-коду проекта и не должна автоматически становиться шаблоном для
любого прикладного модуля.

## 0. `tab-rhythm` и семантика — это разные слои

Если пользователь спорит именно про табы, пустые строки и визуальный ритм
вложенного блока в IDE, не смешивайте это с отдельным решением про именованные
переменные.

Нельзя смешивать:

```bsl
ПривилегированныйРежим = Истина;
ПакетныйЗапрос = Истина;

Данные = РХ_АкиЗапросы.ВыполнитьЗапрос(..., ПривилегированныйРежим, ПакетныйЗапрос);
```

с вопросом:

```text
<TAB><TAB><TAB>СтрокаТовары = Новый Структура();
<TAB><TAB><TAB>ЗаполнитьЗначенияСвойств(СтрокаТовары, ВыборкаТовары);
<TAB><TAB><TAB>
<TAB><TAB><TAB>ТоварыРеализации.Добавить(СтрокаТовары);
```

Первое относится к `method-composition.md`, второе — к
`bsl-formatting.md`.

## 0.1. Внутренний блок как прямоугольник в IDE

Менее удачно:

```text
<TAB><TAB>Пока ВыборкаТовары.Следующий() Цикл
<TAB><TAB><TAB><TAB>СтрокаТовары = Новый Структура();
<TAB><TAB><TAB><TAB>ЗаполнитьЗначенияСвойств(СтрокаТовары, ВыборкаТовары);
<TAB><TAB><TAB>
<TAB><TAB><TAB><TAB>ТоварыРеализации.Добавить(СтрокаТовары);
<TAB><TAB>КонецЦикла;
```

Лучше:

```text
<TAB><TAB>Пока ВыборкаТовары.Следующий() Цикл
<TAB><TAB><TAB>СтрокаТовары = Новый Структура();
<TAB><TAB><TAB>ЗаполнитьЗначенияСвойств(СтрокаТовары, ВыборкаТовары);
<TAB><TAB><TAB>
<TAB><TAB><TAB>ТоварыРеализации.Добавить(СтрокаТовары);
<TAB><TAB>КонецЦикла;
```

Во втором варианте IDE показывает цельную геометрию уровня: sibling-строки и
пустая строка держат один tab-уровень.

## 0.2. Пустая строка сразу после `Тогда`

Менее удачно:

```bsl
Если ЗначениеЗаполнено(РезультатПоиска.Объект) Тогда
	ВозвращаемоеЗначение = РезультатПоиска.Объект;
ИначеЕсли РХ_ЭтоСтроковыйGUID(Ид) Тогда
```

Лучше:

```bsl
Если ЗначениеЗаполнено(РезультатПоиска.Объект) Тогда
	
	ВозвращаемоеЗначение = РезультатПоиска.Объект;
ИначеЕсли РХ_ЭтоСтроковыйGUID(Ид) Тогда
```

Здесь пустая строка не декоративна: она сразу открывает тело ветки как
отдельную визуальную область.

## 0.3. Однострочный внутренний `Если` не нужно разрежать

Плохо:

```bsl
Если ЗначениеЗаполнено(РезультатПоGUID) Тогда
	
	ВозвращаемоеЗначение = РезультатПоGUID;
КонецЕсли;
```

Лучше:

```bsl
Если ЗначениеЗаполнено(РезультатПоGUID) Тогда
	ВозвращаемоеЗначение = РезультатПоGUID;
КонецЕсли;
```

Если внутри ветки ровно одно короткое действие и блок сразу закрывается,
air-gap не добавляйте.

## 0.4. Многострочная ветка после `Если` требует air-gap

Менее удачно:

```bsl
Если ЗначениеЗаполнено(Партнер) Тогда
	Запрос = Новый Запрос();
	Запрос.Текст = ТекстЗапросаНайтиКонтрагентаПоИдентификатору();
	Запрос.УстановитьПараметр("Партнер", Партнер);
```

Лучше:

```bsl
Если ЗначениеЗаполнено(Партнер) Тогда
	
	Запрос = Новый Запрос();
	Запрос.Текст = ТекстЗапросаНайтиКонтрагентаПоИдентификатору();
	Запрос.УстановитьПараметр("Партнер", Партнер);
```

Если ветка в этом примере открывает отдельную рабочую стадию из нескольких
строк, пустая строка после `Тогда` помогает увидеть её как самостоятельный
блок.

## 0.5. Вложенный `Если/ИначеЕсли` применяет то же правило

Менее удачно:

```bsl
Если Выборка.Количество() > 1 Тогда
	ТекстОшибки = СтрШаблон(...);
	БУС_ОбщегоНазначенияВызовСервера.ДобавитьВЛог(...);
ИначеЕсли Выборка.Следующий() Тогда
	ВозвращаемоеЗначение = Выборка.Ссылка;
КонецЕсли;
```

Лучше:

```bsl
Если Выборка.Количество() > 1 Тогда
	
	ТекстОшибки = СтрШаблон(...);
	БУС_ОбщегоНазначенияВызовСервера.ДобавитьВЛог(...);
ИначеЕсли Выборка.Следующий() Тогда
	
	ВозвращаемоеЗначение = Выборка.Ссылка;
КонецЕсли;
```

Если вложенная ветка сама содержит отдельную стадию из нескольких строк, она
открывается так же, как и верхний `Если`: правило рекурсивно.

## 1. Имена функций

Плохо:

```bsl
Функция СоздатьКонтекстВыгрузки(...)
Функция СформироватьДетализациюФлагов(...)
```

Лучше:

```bsl
Функция НовыйКонтекстВыгрузки(...)
Функция ДетализацияФлаговВыгрузки(...)
```

## 2. Пошаговый вызов вместо inline-комбинаторики

Плохо:

```bsl
ИнтеграцияНаСервере.СообщитьЗаписьЖурнала(
    СтрШаблон("%1 %2", ТекущаяДата(), ТекстНачала),
    ИмяСобытияЖурнала,
    НастройкиВыгрузки.Версия,
    ДетализацияФлаговВыгрузки(НастройкиВыгрузки)
);
```

Лучше:

```bsl
ТекстСообщения = СтрШаблон("%1 %2", ТекущаяДата(), ТекстНачала);
ДетализацияФлагов = ДетализацияФлаговВыгрузки(НастройкиВыгрузки);

ИнтеграцияНаСервере.СообщитьЗаписьЖурнала(
    ТекстСообщения,
    ИмяСобытияЖурнала,
    НастройкиВыгрузки.Версия,
    ДетализацияФлагов
);
```

## 3. Преобразование значения

Плохо:

```bsl
Запись.Вставить("longitude", СтрокаКоординаты(Запись["longitude"]));
```

Лучше:

```bsl
Долгота = Запись["longitude"];
ДолготаСтрокой = СтрокаКоординаты(Долгота);
Запись.Вставить("longitude", ДолготаСтрокой);
```

## 4. Запрещенная ошибка при пошаговом стиле

Нельзя:

```bsl
Широта = Запись["latitude"];
ШиротаСтрокой = СтрокаКоординаты(Широта);
Запись.Вставить("latitude", Широта);
```

Нужно:

```bsl
Широта = Запись["latitude"];
ШиротаСтрокой = СтрокаКоординаты(Широта);
Запись.Вставить("latitude", ШиротаСтрокой);
```

## 5.1. `Запрос.Текст` через helper, а не inline

Менее удачно:

```bsl
Запрос = Новый Запрос();
Запрос.Текст =
	"ВЫБРАТЬ РАЗРЕШЕННЫЕ РАЗЛИЧНЫЕ
	|	Контрагенты.Ссылка КАК Ссылка
	|ИЗ
	|	Справочник.Контрагенты КАК Контрагенты";
```

Лучше:

```bsl
Запрос = Новый Запрос();
Запрос.Текст = ТекстЗапросаНайтиКонтрагентаПоИдентификатору();
```

В таком примере основной метод читается лучше как сценарий, а не как тело
SQL-like литерала.

## 5.2. Отдельная область `ТекстыЗапросов`

Лучше:

```bsl
#Область СлужебныеПроцедурыИФункции
...
#КонецОбласти

#Область ТекстыЗапросов

Функция ТекстЗапросаНайтиКонтрагентаПоИдентификатору()
	ВозвращаемоеЗначение = "
	|ВЫБРАТЬ РАЗРЕШЕННЫЕ РАЗЛИЧНЫЕ
	|	Контрагенты.Ссылка КАК Ссылка
	|ИЗ
	|	Справочник.Контрагенты КАК Контрагенты
	|ГДЕ
	|	Контрагенты.Партнер = &Партнер
	|	И НЕ Контрагенты.ПометкаУдаления
	|";

	Возврат ВозвращаемоеЗначение;
КонецФункции

#КонецОбласти
```

Здесь важно не только вынесение запроса в helper, но и локальная геометрия
литерала: открывающая кавычка стоит на строке `ВозвращаемоеЗначение = "`, а
строки текста запроса сразу идут как `|...` без дополнительной пустой строки
или промежуточного смещения; отступы внутри текста запроса после `|` пишутся
табами, а не пробелами.

Плохо:

```bsl
Процедура ВыполнитьЭтапыВыгрузки(...) Экспорт
Функция НовыйКонтекстВыгрузки(...) Экспорт
Функция ДетализацияФлаговВыгрузки(...) Экспорт
```

Лучше:

```bsl
Процедура ВыгрузитьСправочники(...) Экспорт

Функция НовыйКонтекстВыгрузки(...)
Процедура ВыполнитьЭтапыВыгрузки(...)
Функция ДетализацияФлаговВыгрузки(...)
```

## 6. Лишний вспомогательный метод

Плохо:

```bsl
Функция ФлагНоменклатуры(КонтекстВыгрузки)
    Возврат КонтекстВыгрузки.Настройки.ФлагНоменклатура;
КонецФункции
```

Лучше:

```bsl
Если РХ_АкиКонтекстВыгрузки.ЗначениеФлагаКонтекста(КонтекстВыгрузки, "ФлагНоменклатура") Тогда
    ...
КонецЕсли;
```

## 7. Единая форма функции с fallback

Менее удачно:

```bsl
Функция ПакетВыгрузки(ПакетыВыгрузки, ИмяПакета)
    Если ПакетыВыгрузки.Свойство(ИмяПакета) Тогда
        Возврат ПакетыВыгрузки[ИмяПакета];
    КонецЕсли;

    Возврат Новый Массив();
КонецФункции
```

Лучше:

```bsl
Функция ПакетВыгрузки(ПакетыВыгрузки, ИмяПакета)
    ВозвращаемоеЗначение = Новый Массив();

    Если ПакетыВыгрузки.Свойство(ИмяПакета) Тогда
        ВозвращаемоеЗначение = ПакетыВыгрузки[ИмяПакета];
    КонецЕсли;

    Возврат ВозвращаемоеЗначение;
КонецФункции
```

## 8. Единая форма простой функции доступа

Плохо:

```bsl
Функция КонтекстОбмена(КонтекстВыгрузки)
    Возврат КонтекстВыгрузки.КонтекстОбмена;
КонецФункции
```

Лучше:

```bsl
Функция КонтекстОбмена(КонтекстВыгрузки)
    ВозвращаемоеЗначение = КонтекстВыгрузки.КонтекстОбмена;

    Возврат ВозвращаемоеЗначение;
КонецФункции
```

## 9. Флаги сценария сначала, ветки потом

Менее удачно:

```bsl
Если РХ_АкиКонтекстВыгрузки.ФлагКонтекстаВыгрузки(КонтекстВыгрузки, "ФлагСообщения") Тогда
    ...
КонецЕсли;

Если РХ_АкиКонтекстВыгрузки.ФлагКонтекстаВыгрузки(КонтекстВыгрузки, "ФлагСкидки") Тогда
    ...
КонецЕсли;
```

Лучше:

```bsl
ВыгружатьСообщения = РХ_АкиКонтекстВыгрузки.ФлагКонтекстаВыгрузки(КонтекстВыгрузки, "ФлагСообщения");
ВыгружатьСкидки = РХ_АкиКонтекстВыгрузки.ФлагКонтекстаВыгрузки(КонтекстВыгрузки, "ФлагСкидки");

Если ВыгружатьСообщения Тогда
    ...
КонецЕсли;

Если ВыгружатьСкидки Тогда
    ...
КонецЕсли;
```

Так проще читать сценарий и легче заметить ошибку в строковом имени флага.

## 9.1. Канонический регистр логических операторов

Менее удачно:

```bsl
Если НЕ ПравоДоступа ИЛИ ОшибкаПроверки Тогда
    РезультатПроверки = Ложь;
КонецЕсли;
```

Лучше:

```bsl
Если Не ПравоДоступа Или ОшибкаПроверки Тогда
    РезультатПроверки = Ложь;
КонецЕсли;
```

Для этого skill-а формы `НЕ` и `ИЛИ` в изменяемом BSL-коде считаются обычной
локальной style-ошибкой и исправляются автоматически.

## 9.2. Булеву колонку через `Ложь` или `Истина` не схлопывать

Менее удачно:

```bsl
ВозвращаемоеЗначение = РольПросмотраДоступна
	Или ЕстьПравоЗапускаПеревода(ПользовательСсылка)
	Или ЕстьПравоАдминистрированияИнтеграции(ПользовательСсылка);
```

Лучше:

```bsl
ВозвращаемоеЗначение = (Ложь
	Или РольПросмотраДоступна
	Или ЕстьПравоЗапускаПеревода(ПользовательСсылка)
	Или ЕстьПравоАдминистрированияИнтеграции(ПользовательСсылка)
);
```

И симметрично для `И`:

```bsl
ВозвращаемоеЗначение = (Истина
	И Проверка1()
	И Проверка2()
	И Проверка3()
);
```

Такая форма полезна, когда все условия должны читаться в одной колонке, а
отдельные строки удобно быстро добавлять, временно комментировать или менять
местами.

## 10. В цикле использовать уже вычисленный порядок обхода

Менее удачно:

```bsl
Для Каждого ИмяПакета Из ПорядокПакетовНоменклатуры() Цикл
    ...
КонецЦикла;
```

Лучше:

```bsl
ПорядокПакетов = ПорядокПакетовНоменклатуры();

Для Каждого ИмяПакета Из ПорядокПакетов Цикл
    ...
КонецЦикла;
```

## 11. Последовательность стадий orchestration-метода

Менее удачно:

```bsl
Функция ЭтапОбщихСправочников(ПараметрыОбмена) Экспорт

	ДанныеДляОтправки = Новый Структура();

	ПодготовкаСклады(ДанныеДляОтправки);
	...
	ПодготовкаТипыТочек(ДанныеДляОтправки);

	ПакетСклады = ПакетИзДанныхДляОтправки(ДанныеДляОтправки, "Склады");
	...
	ПакетПриоритетныеПозиции = ПакетИзДанныхДляОтправки(ДанныеДляОтправки, "ПриоритетныеПозиции");

	ВозвращаемоеЗначение = НовыйРезультатЭтапа();
	ВозвращаемоеЗначение.Пакеты.Вставить("Склады", ПакетСклады);
	...
	ВозвращаемоеЗначение.Пакеты.Вставить("ПриоритетныеПозиции", ПакетПриоритетныеПозиции);
	ВозвращаемоеЗначение.КонтекстЭтапа.Вставить("ПараметрыОбмена", ПараметрыОбмена);

	Возврат ВозвращаемоеЗначение;

КонецФункции
```

Лучше:

```bsl
Функция ЭтапОбщихСправочников(ПараметрыОбмена) Экспорт

	ДанныеДляОтправки = Новый Структура();

	ПодготовкаСклады(ДанныеДляОтправки);
	...
	ПодготовкаТипыТочек(ДанныеДляОтправки);

	ПакетСклады = ПакетИзДанныхДляОтправки(ДанныеДляОтправки, "Склады");
	...
	ПакетПриоритетныеПозиции = ПакетИзДанныхДляОтправки(ДанныеДляОтправки, "ПриоритетныеПозиции");

	ВозвращаемоеЗначение = НовыйРезультатЭтапа();

	ВозвращаемоеЗначение.Пакеты.Вставить("Склады", ПакетСклады);
	...
	ВозвращаемоеЗначение.Пакеты.Вставить("ПриоритетныеПозиции", ПакетПриоритетныеПозиции);

	ВозвращаемоеЗначение.КонтекстЭтапа.Вставить("ПараметрыОбмена", ПараметрыОбмена);

	Возврат ВозвращаемоеЗначение;

КонецФункции
```

Во втором варианте orchestration-метод читается как цепочка стадий:
`подготовить данные -> вычислить пакеты -> создать результат -> заполнить пакеты -> заполнить контекст -> вернуть`.

Пустые строки здесь не декоративны: они маркируют переход между стадиями.

## 12. В контейнер вставлять уже вычисленное значение

Менее удачно:

```bsl
СоответствиеШаблоновКонтрагентам.Вставить(
    "templates",
    ОбщегоНазначенияКлиентСервер.ЗначениеВМассиве(ВнешнийИдентификатор(Выборка.Ссылка))
);
```

Лучше:

```bsl
ВнешнийИдентификаторШаблона = ВнешнийИдентификатор(Выборка.Ссылка);
ШаблоныКОтправке = ОбщегоНазначенияКлиентСервер.ЗначениеВМассиве(ВнешнийИдентификаторШаблона);

СоответствиеШаблоновКонтрагентам.Вставить("templates", ШаблоныКОтправке);
```

## 13. Внутри цикла не повторять сложное обращение к контейнеру

Менее удачно:

```bsl
Для Каждого ИмяПакета Из ПорядокПакетов Цикл
    ДанныеОтправлены = ИнтеграцияНаСервере.РХ_ОтправитьДанные(
        ИмяПакета,
        ПакетыНоменклатуры[ИмяПакета],
        ...
    );
КонецЦикла;
```

Лучше:

```bsl
Для Каждого ИмяПакета Из ПорядокПакетов Цикл
    ПакетКОтправке = ПакетыНоменклатуры[ИмяПакета];

    ДанныеОтправлены = ИнтеграцияНаСервере.РХ_ОтправитьДанные(
        ИмяПакета,
        ПакетКОтправке,
        ...
    );
КонецЦикла;
```

## 13. Длинный запрос выносить в `ТекстЗапроса...`

Менее удачно:

```bsl
Процедура ПодготовкаСклады(ДанныеДляОтправки)
	Запрос = Новый Запрос(
```

## 19. Предметный объект не прятать в `Добавить(...)`

Менее удачно:

```bsl
ПараметрыВыбораСклада = Новый Массив();
ПараметрыВыбораСклада.Добавить(Новый ПараметрВыбора("Отбор.ТипСклада", Перечисления.ТипыСкладов.ОптовыйСклад));

Элементы.Склад.ПараметрыВыбора = Новый ФиксированныйМассив(ПараметрыВыбораСклада);
```

Лучше:

```bsl
ПараметрВыбораТипСклада = Новый ПараметрВыбора("Отбор.ТипСклада", Перечисления.ТипыСкладов.ОптовыйСклад);

ПараметрыВыбораСклада = Новый Массив();
ПараметрыВыбораСклада.Добавить(ПараметрВыбораТипСклада);

Элементы.Склад.ПараметрыВыбора = Новый ФиксированныйМассив(ПараметрыВыбораСклада);
```

Здесь отдельная переменная нужна для самого `ПараметрВыбора`, потому что это
самостоятельный объект сценария и удобная точка останова: значение можно сразу
посмотреть и временно подменить в отладчике. Для `Новый ФиксированныйМассив(...)`
отдельная переменная уже не нужна: это техническая оболочка над
подготовленным массивом.

## 20. Пустой конструктор писать со скобками

Менее удачно:

```bsl
ВозвращаемоеЗначение = Новый Массив;
ПараметрыОтбора = Новый Структура;
СоответствиеДанных = Новый Соответствие;
```

Лучше:

```bsl
ВозвращаемоеЗначение = Новый Массив();
ПараметрыОтбора = Новый Структура();
СоответствиеДанных = Новый Соответствие();
```

В этом примере явные скобки поддерживают единую форму вызова конструктора,
даже если аргументов пока нет.

## 21. Пустая строка внутри метода не теряет отступ

Нотация для примера:

- `<TAB>` — табуляция на иначе пустой строке.
- `<EMPTY>` — полностью пустая строка без табуляции.

Плохо:

```text
Процедура Пример()
<TAB>Если Условие Тогда
<TAB><TAB>Действие();
<EMPTY>
<TAB>КонецЕсли;
<EMPTY>
КонецПроцедуры
```

Лучше:

```text
Процедура Пример()
<TAB>Если Условие Тогда
<TAB><TAB>Действие();
<TAB><TAB>
<TAB>КонецЕсли;
<TAB>
КонецПроцедуры
```

Полное правило и частные случаи храните в
`references/bsl-formatting.md`, а не в отдельных ad hoc-оговорках.

## 22. Пустая строка не уводит следующий оператор глубже

Нотация для примера:

- `<TAB>` — табуляция на иначе пустой строке.

Плохо:

```text
<TAB><TAB><TAB><TAB>СуммаДолг = СуммаДолг + ВыборкаДетали.СуммаДолг;
<TAB><TAB><TAB><TAB><TAB>
<TAB><TAB><TAB><TAB><TAB>ВнешнийИдентификаторПартнера = ...
<TAB><TAB><TAB><TAB><TAB>ВнешнийИдентификаторДоговораСтроки = ...
```

Лучше:

```text
<TAB><TAB><TAB><TAB>СуммаДолг = СуммаДолг + ВыборкаДетали.СуммаДолг;
<TAB><TAB><TAB><TAB>
<TAB><TAB><TAB><TAB>ВнешнийИдентификаторПартнера = ...
<TAB><TAB><TAB><TAB>ВнешнийИдентификаторДоговораСтроки = ...
```

Пустая строка внутри блока сохраняет отступ этого блока, но не образует для
следующей операции новый уровень вложенности.

## 23. Длинный `СтрШаблон(...)` сначала собирать в уже вычисленное значение

Плохо:

```bsl
Для Каждого Долг Из МассивДолговИзОблака Цикл
    ВозвращаемоеЗначение.Вставить(
        СтрШаблон("%1_%2_%3", Долг["client_extid"], Долг["contract_extid"], Долг["firm_extid"]),
        Долг["debt"]
    );
КонецЦикла;
```

Лучше:

```bsl
Для Каждого Долг Из МассивДолговИзОблака Цикл
    ВнешнийИдентификаторПартнера = Долг["client_extid"];
    ВнешнийИдентификаторДоговора = Долг["contract_extid"];
    ВнешнийИдентификаторОрганизации = Долг["firm_extid"];
    КлючДолга = СтрШаблон("%1_%2_%3",
        ВнешнийИдентификаторПартнера,
        ВнешнийИдентификаторДоговора,
        ВнешнийИдентификаторОрганизации
    );
    СуммаДолга = Долг["debt"];

    ВозвращаемоеЗначение.Вставить(КлючДолга, СуммаДолга);
КонецЦикла;
```

Так `СтрШаблон(...)` становится частным случаем общего правила: в методе
сначала держим уже вычисленные переменные, а потом используем их в вызове,
контейнере или присваивании.
